# 【南开大学26C++】器官保卫战 (HealthGame)

欢迎来到 **《器官保卫战》（HealthGame / 健康生存模拟器）**！这是一款主打【真实生理模拟与硬核生存策略】的独立游戏，同时也是本人的 C++ 课程大作业项目。

在这个游戏里，你最大的敌人是你自己的【身体】和【时间】。从 0 岁开始管理血压、血脂、血糖、免疫和资金，观察三维人体与器官的病灶，通过体检、治疗、科研和理财活到 110 岁。

## ✨ 当前版本：v0.6 Anatomy 3D 平衡版

- 使用三维人体与器官图谱，可旋转、缩放、剖视和点击查看结构；年龄会改变模型形态。
- 54 种疾病绑定不同器官/解剖结构，并有疾病、分期和治疗进度对应的可视化表现。
- 天赋改为四条不同路线：家境管资金，气运管重病风险与治疗容错，健康管耐受与康复，科研管筛查和长期成本。
- 发病采用有界风险模型：轻病可复发；重大疾病全身至少间隔 3 游戏年；切除阑尾/胆囊后不会生成对应疾病；肿瘤治疗不再获得错误的终身免疫。
- 支持同器官合并病，小病不能充当阻挡重病的“盾牌”；急性事件与癌症潜伏进展分开处理。
- 游戏内“存档管理”提供自动档、独立手动档、关闭补存与安全读档；默认保存在程序旁 `saves`，不可写时自动回退到用户数据目录。
- 存档 JSON v3 保存病史、结构切除、复发保护期、合并病、治疗阶段和随机数状态，防止读档刷随机或清除冷却；兼容 v2 存档迁移。

> 这是一款游戏和教学图谱风格作品。疾病概率、金额、疗效、年龄变化和可视化均为玩法设定，不能用于诊断或现实医疗决策。

## 📝 核心项目报告

### 1. 项目问题描述
随着现代社会生活节奏加快，人们面临诸多健康风险。本项目旨在开发一款基于 C++ 和 Qt 框架的生存策略模拟游戏——《器官保卫战》。玩家需要管理角色的健康指标（血压、血糖、血脂）、免疫力、金钱，以及分配初始天赋（家境、健康、科研、气运），在生老病死的自然规律和突发疾病中尽可能长久地生存，并通过策略博弈（如体检、科研）攻克绝症和寿命极限。

### 2. 项目实际意义
1. **健康教育科普**：通过模拟高压科研对身体指标的负面影响，以及引入“3年一次体检”查出早期癌症的机制，向玩家科普防患于未然、定期体检的现实重要性。
2. **编程能力综合实践**：本项目综合运用了 C++ 面向对象编程、Qt 信号与槽机制、状态机设计模式等核心技术，锻炼了复杂软件架构和工程实践能力。

### 3. 技术路线及算法描述
1. **技术路线**：使用 C++17 和 Qt 6，基于 Qt Widgets + OpenGL 3.3 开发三维交互界面；游戏引擎、疾病规则、存档仓库和 UI 分层，药剂、手术、保健品与器官状态由数据模型驱动。
2. **核心算法**：
   - **时间驱动引擎**：使用 `QTimer` 作为游戏心跳 (Tick)，驱动年龄增长、指标衰减和疾病判定。
   - **动态概率模型**：按轻/中/重大病类别计算有界危险率，结合年龄、体征、天赋、病史和恢复期生成事件，避免病种数量叠加成连续爆发。
   - **隐性疾病状态机**：针对 5 级严重疾病（如癌症），设计了“潜伏期(早期) -> 中期 -> 晚期爆发”的状态机算法。玩家必须主动调用“体检”算法才能在早期干预，否则将在晚期强制爆发，治疗成功率呈指数级下降。

### 4. 开发过程中遇到的难点及解决方法
1. **难点1：多并发健康指标的 UI 联动与精准警报。**
   - *问题*：初期存在逻辑 Bug，当血压、血糖、血脂中有一项异常时，整个标签页都会标红，无法精准定位。
   - *解决*：引入 HTML 富文本格式动态渲染 `QLabel`，在底层对每项指标进行独立的条件判断和 `<font color='red'>` 着色封装。
2. **难点2：游戏后期的数值膨胀与绝症平衡性设计。**
   - *问题*：前期金币容易溢出，导致后期治疗毫无生存压力，失去策略性。
   - *解决*：深度重构经济系统。将成年后收入与“科研”天赋绑定，并引入双刃剑机制（科研过高会加速身体损耗）。同时引入多阶段治疗算法，大幅提高高级特效药和绝症手术的费用。特别是 80岁与 100岁的大限机制，每次强制扣除 100 万金币进行续命。
3. **难点3：如何体现 5 级以上疾病的真实感。**
   - *解决*：独创了“隐性疾病进展算法”，疾病在后台静默升级，逼迫玩家养成每 3 年花费 3 万元进行体检的习惯，极大增强了游戏的现实代入感。

### 5. AI 工具使用披露
- **AI工具名称及版本**：Trae IDE (内置 Claude 3.5 Sonnet / Gemini 模型)
- **具体用途**：代码开发（辅助构建 Qt UI 组件、优化信号与槽机制）、数据分析与逻辑推演（疾病概率与经济系统的数值平衡调整）、Bug修复（排查 UI 富文本变色问题，修复疾病年龄段分布断层）。
- **使用位置**：核心游戏循环 `GameEngine.cpp` 的状态机设计、`mainwindow.cpp` 的 UI 更新逻辑，以及本报告文档的文案结构梳理。

## 🚀 如何运行与游玩

- **免安装版**：在 [Releases](../../releases) 下载最新版绿色压缩包，解压后双击 `HealthGame.exe`。请保留程序旁的 `anatomy`、`platforms` 等目录。
- **存档**：首次启动或点击“存档管理”即可查看、继续或手动保存，不需要手动寻找文件。
- **自行编译**：使用 Qt 6.5+、C++17、OpenGL 3.3；可用 Qt Creator 打开 `第四版/CMakeLists.txt`，或执行 `cmake -S 第四版 -B build -G Ninja` 后构建。
